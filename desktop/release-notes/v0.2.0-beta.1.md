# Beta EasySbatch v0.2.0-beta.1

This Beta moves the remaining core Web workflows into the native desktop
product while keeping final Slurm submission user-controlled.

## Added

- automatic shared environment and software catalog for `10.158.132.77`;
- safe empty catalog and no-command environment fallback for other hosts;
- manual New task panel with environment, software, resource, input, output,
  preparation-step, and launcher controls;
- fresh all-partition resource recommendation with an explicit evidence notice;
- user-driven, read-only remote directory picker limited to 500 metadata rows;
- immutable script-preview digest: changing a draft invalidates its approval;
- full JobSpec, evidence, script path, log path, and failure detail in Task history;
- stricter assistant sequence: scan, list profiles/catalog, validate, recommend,
  render, then save the unchanged reviewed draft.

## Safety and current limitations

- The model cannot submit jobs, run Shell, browse remote directories, edit
  files, use the Web, or select physical compute nodes.
- Remote directory browsing does not read or upload file contents.
- Cluster credentials remain owned by system OpenSSH and are never stored by
  Beta EasySbatch.
- The test installers are unsigned. Operating-system keychain migration,
  signed production installers, and production automatic updates remain future
  release work.
- Intel macOS is not included; packages target Windows x64 and Apple Silicon.

Build and package validation must be completed by GitHub Actions. Local source
checks are not evidence that either native installer builds successfully.
