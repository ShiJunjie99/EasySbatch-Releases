# Beta EasySbatch v0.1.0-beta.1

This is the first native DSH-based Beta of EasySbatch. It is published from
the verified cross-platform build run
[#34921335178](https://github.com/ShiJunjie99/EasySbatch-Releases/actions/runs/34921335178).

## Downloads

- Windows x64: the unsigned `.exe` installer.
- macOS Apple Silicon: the unsigned `.dmg` or `.zip` package.
- Intel macOS is intentionally not included.

## Beta safety boundary

The application runs as a native Electron desktop package without opening a
browser or listening on localhost. It exposes project scanning, strict JobSpec
validation, and sbatch script preview. SSH, Slurm submission, arbitrary Shell
and filesystem access, Web search, subagents, telemetry, third-party plugins,
and automatic updates remain disabled in this Beta.

Model credentials currently use DSH's isolated local credential store rather
than the operating-system keychain. Use a restricted test API key and do not
bundle production credentials with test packages.

These packages are unsigned. Windows SmartScreen and macOS Gatekeeper may ask
the tester to explicitly allow the first launch. Verify downloads against the
included `SHA256SUMS` file.

Validation: 2,085 Python tests passed, and both native packaging jobs completed
successfully.
