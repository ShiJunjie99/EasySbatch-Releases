# EasySbatch 0.1.0-alpha.1 (draft)

EasySbatch is an alpha AI-assisted Slurm workflow. It requires SSH access to a
Linux cluster with Slurm and a compatible user-level server/Worker deployment.

The optional AI path uses the user's own DeepSeek API key, stored locally in an
OS credential store. The key is not uploaded to the cluster. AI requests remain
subject to bounded context, strict schema validation, Harness checks, and user
review. Manual mode remains available when AI is missing or unavailable.

Assets are built by the tag-gated GitHub Actions workflow. Windows and macOS
alpha artifacts are unsigned/not notarized. Verify `SHA256SUMS` before use.

Known limitations: Slurm only; SSH is required; supported job behavior depends
on the audited Server Catalog; complex MPI/multinode/GPU behavior is not
universally verified; native Windows/macOS credential tests and real two-user
AI acceptance are release-readiness gates.
