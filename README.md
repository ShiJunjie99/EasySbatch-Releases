# EasySbatch Releases

Binary releases for EasySbatch, an AI-assisted Slurm workflow for HPC users.

Download the latest **Pre-release** from [Releases](../../releases). Verify the
download with `SHA256SUMS` before running it.

## Alpha requirements

- An HPC cluster administrator must provide the EasySbatch server/Worker.
- SSH access and system OpenSSH are required.
- AI is optional. If enabled, each user supplies their own DeepSeek API key;
  the key is stored on the user's device and is not uploaded to the cluster.
- These unsigned alpha builds are for controlled testing, not production jobs.

The source repository and deployment configuration are maintained separately.
This repository contains release artifacts only.
