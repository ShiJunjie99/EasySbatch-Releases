# GROMACS version-only Catalog smoke

This small project documents an installed GROMACS invocation:

```bash
gmx --version
```

No project input files, compilation, simulation, MPI launcher, or GPU allocation
are needed for this version query. The server Catalog supplies the installed
GROMACS executable and environment; this README deliberately contains no
server absolute path. M8-A only analyzes and previews this command: do not submit
or execute this project as part of the Smart Prepare verification.
